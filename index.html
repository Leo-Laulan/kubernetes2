2. Pods : Syntax & Comportement

apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
  namespace: ns-llaula
  labels:
    app: nginx
spec:
  containers:
  - name: nginx-container
    image: nginx
  • Cycle de vie : Pending (attente de placement node/recuperation image) → Running (au moins un conteneur tourne) → Succeeded / Failed.
  • Conteneurs multiples : Partagent l'IP, le localhost (conflit si meme port) et les volumes.
  • Commandes cles :
    • Extraire un champ specifique : kubectl get pod <nom> -o jsonpath='{.spec.containers[*].name}'
    • Executer sans shell externe : kubectl exec -it <nom> -n <ns> -- hostname
    • Lister tous les namespaces : kubectl get pods -A (syntaxe -ALL ou -n all invalide).

3. ReplicaSet : Reconciliation & Selecteurs

apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: rs-nginx
  namespace: ns-llaula
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx-container
        image: nginx
  • Decouplage strict : Le ReplicaSet ne sait pas d'ou vient un pod. Il match uniquement via matchLabels.
  • Excedent de pods : Si 3 sont demandes et qu'un pod orphelin avec les memes labels est cree, le total passe a 4. Le controlleur passe un pod en Terminating immediatement.
  • Pod tue manuellement : Le controlleur observe l'ecart (2 presents vs 3 requis) et planifie un nouveau pod (Pending → ContainerCreating → Running).
  • Echelle dynamique : kubectl scale rs rs-nginx --replicas=4 -n ns-llaula.

4. Deployments : Gestion des Versions

apiVersion: apps/v1
kind: Deployment
metadata:
  name: dep-nginx
  namespace: ns-llaula
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
  • Hierarchie : Deployment → cree et controle des ReplicaSets → creent et controlent des Pods.
  • Mise a jour d'image : kubectl set image deployment/dep-nginx nginx=nginx:1.16.1 -n ns-llaula.
  • Erreur d'image (ex: nginx:1.161) : Le nouveau ReplicaSet cree un pod qui passe en erreur (ImagePullBackOff). L'ancien ReplicaSet n'est pas supprime et conserve ses pods actifs pour eviter toute coupure.
  • Historique et Rollback :
    • Voir les revisions : kubectl rollout history deployment/dep-nginx -n ns-llaula
    • Retour arriere : kubectl rollout undo deployment/dep-nginx --to-revision=1 -n ns-llaula
    • Statut en temps reel : kubectl rollout status deployment/dep-nginx -n ns-llaula
